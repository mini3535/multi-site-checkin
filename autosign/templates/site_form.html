直接粘贴 Cookie 即可，无需准备 JSON。此方式只连接签到页所在主机。新任务需要提供一种登录凭据；编辑时留空可保留原会话。凭据会加密保存，页面不会回显。

在哪里复制登录 Cookie？
  1. 在自己的电脑浏览器中登录目标网站，打开签到页面。
  2. 按 F12（Mac 可按 ⌥⌘I）打开开发者工具，选择“网络 / Network”，然后刷新页面。
  3. 选择发往签到页面所在域名的已登录请求，在“请求标头 / Request Headers”里找到 Cookie，复制它的值并粘贴到上方，不含 Cookie: 前缀。

Cookie 相当于登录凭据，请只保存到你自己的签到助手。当前仍需手动复制，没有自动采集功能。

其他连接方式：导入完整登录会话

如果网站还依赖本地存储或多个登录域名，可用以下备用方式。Cookie、会话文件和会话文本三选一，不要同时填写。

上传浏览器导出的完整会话 JSON（包含 cookies 和 origins），最多 512 KiB。

在你自己的电脑上运行项目的会话导出工具，在打开的浏览器中人工登录，完成后按 Enter 导出。登录密码与验证过程由你操作。

填写按钮文字会自动生成点击步骤；多步流程请清空按钮文字并在这里填写 JSON。

每一步可使用 click、fill 或 wait，selector 填唯一目标元素。起始页面会自动打开。

[
  {
    "action": "click",
    "selector": "<实际签到按钮的唯一选择器>",
    "timeout_ms": 5000
  }
]

CSS 示例：#daily-checkin；文字选择器示例：text=签到。

fill 步骤额外填写 value；wait 使用 selector 等待目标元素出现。
