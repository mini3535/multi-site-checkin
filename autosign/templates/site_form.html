直接粘贴 Cookie 即可，无需准备 JSON。此方式只连接签到页所在主机。新任务需要提供一种登录凭据；编辑时留空可保留原会话。凭据会加密保存，页面不会回显。

在哪里复制登录 Cookie？
  1. 在自己的电脑浏览器中登录目标网站，打开签到页面。
  2. 按 F12（Mac 可按 ⌥⌘I）打开开发者工具，选择“网络 / Network”，然后刷新页面。
  3. 选择发往签到页面所在域名的已登录请求，在“请求标头 / Request Headers”里找到 Cookie，复制它的值并粘贴到上方，不含 Cookie: 前缀。

Cookie 相当于登录凭据，请只保存到你自己的签到助手。当前仍需手动复制，没有自动采集功能。

无需 JSON，不是模型 API Key。复制已登录请求中 Authorization 的值，可带 Bearer 前缀，不含 Authorization: 字段名。Token 会加密保存，编辑时不回显。

星驰 API 自动使用 auth_token 并读取账号资料；其他网站默认使用 access_token，字段名不同时可在高级设置调整。

在哪里复制登录 Token？
  1. 在官网登录，打开开发者工具的“网络 / Network”，刷新页面。
  2. 选择已登录的账号信息请求（星驰可选 /api/v1/auth/me），打开“标头 / Headers”。
  3. 在“请求标头 / Request Headers”中复制 Authorization 的值，粘贴到上方。

Token 过期后需要重新登录并更新。不要复制 refresh_token 或模型 API Key。

高级：Token 在网站中的存储字段

对应开发者工具 Application → Local storage 中保存登录 Token 的键名。留空自动选择；更改字段名时需重新粘贴 Token。仅使用请求头、sessionStorage 或需要额外登录资料的网站仍需专用适配或完整会话。

用 Chrome 插件从你已登录的网站导出会话文件，再上传到这里。

先安装会话导出插件
  1. 下载 Chrome 插件 ZIP并解压。
  2. 在 Chrome 地址栏打开 chrome://extensions，开启“开发者模式”，点“加载已解压的扩展程序”，选择解压后的 signin-session-exporter 文件夹。
  3. 登录目标网站并打开登录后的页面，点 Chrome 工具栏的扩展图标，选择“导出并下载”；首次使用时允许访问当前网站。
  4. 回到这里上传下载的 JSON 文件，然后保存并验证签到。

扩展只在你点击时读取当前 HTTPS 网站，并在本机生成文件，不会读取密码或上传会话到其他服务。导出文件等同登录凭据，请只上传到自己的签到助手。依赖 sessionStorage、IndexedDB 或第三方登录的站点可能需要单独适配。

选择刚才下载的 JSON 文件，最多 512 KiB。

或粘贴完整会话 JSON

这是浏览器导出的完整会话对象，不是单独的 Cookie 文本。保存后不会回显。
