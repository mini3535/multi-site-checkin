备用方式：从浏览器开发者工具复制登录 Cookie。普通使用建议改选上方的浏览器扩展连接。凭据会加密保存，页面不会回显。

在哪里复制登录 Cookie？
  1. 在自己的电脑浏览器中登录目标网站，打开签到页面。
  2. 按 F12（Mac 可按 ⌥⌘I）打开开发者工具，选择“网络 / Network”，然后刷新页面。
  3. 选择发往签到页面所在域名的已登录请求，在“请求标头 / Request Headers”里找到 Cookie，复制它的值并粘贴到上方，不含 Cookie: 前缀。

Cookie 相当于登录凭据，请只保存到你自己的签到助手。此备用方式需手动复制；自动读取请选择浏览器扩展连接。

这是高级备用方式。“Bearer”只是登录 Token 常见的前缀，不是模型 API Key。通常需要从开发者工具复制 Authorization 请求标头；普通使用请选择浏览器扩展连接。

星驰 API 自动使用 auth_token 并读取账号资料；其他网站默认使用 access_token，字段名不同时可在高级设置调整。

在哪里复制登录 Token？
  1. 在官网登录，打开开发者工具的“网络 / Network”，刷新页面。
  2. 选择已登录的账号信息请求（星驰可选 /api/v1/auth/me），打开“标头 / Headers”。
  3. 在“请求标头 / Request Headers”中复制 Authorization 的值，粘贴到上方。

Token 过期后需要重新登录并更新。不要复制 refresh_token 或模型 API Key。

高级：Token 在网站中的存储字段

对应开发者工具 Application → Local storage 中保存登录 Token 的键名。留空自动选择；更改字段名时需重新粘贴 Token。仅使用请求头、sessionStorage 或需要额外登录资料的网站仍需专用适配或完整会话。

规则

页面操作

只执行每日签到需要的操作。
选择器应唯一匹配目标元素。

连接浏览器后，会自动填入页面上可见的签到按钮；已有内容会保留，请核对后保存。

高级：自定义页面操作步骤

填写按钮文字会自动生成点击步骤；多步流程请清空按钮文字并在这里填写 JSON。

每一步可使用 click、fill 或 wait，selector 填唯一目标元素。起始页面会自动打开。

[
  {
    "action": "click",
    "selector": "<实际签到按钮的唯一选择器>",
    "timeout_ms": 5000
  }
]

CSS 示例：#daily-checkin；文字选择器示例：text=签到。

fill 步骤额外填写 value；wait 使用 selector 等待目标元素出现。
