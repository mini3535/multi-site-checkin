显示「需要人工恢复」时怎么处理？

自动恢复未完成时，计划任务保持暂停。先在服务器的原安装目录检查 docker compose logs --tail=100 updater、docker compose ps 和磁盘空间。排除问题后运行：

docker compose exec -T updater python -m autosign.updater --recover

命令会重试恢复旧镜像和更新前的数据库。完成后回到本页刷新查看结果；仍失败时保留日志和备份继续排查。不要删除数据卷、手动移除暂停标记或重新生成密钥。

数据备份位于数据卷的 backups/web-updates/，包含数据库和原 .env，请妥善保管。独立更新服务持有 Docker 权限，仅接受本项目固定的更新操作，不开放网络端口。
