# 隐私政策

“签到助手浏览器连接器”只在用户点击识别或导出按钮后读取当前活动 HTTPS 标签页的页面标题、可见签到按钮文字、可见签到状态提示、已加载资源的主机名、Cookie 和 localStorage。

识别范围包含当前标签页中可见且同源的内嵌页面（iframe）；不会读取跨来源内嵌页面，不会采集或发送内嵌链接的查询参数。会话读取范围仍为当前标签页来源。

识别时，扩展将上述页面信息和会话数据发送到用户粘贴的一次性连接链接所指向的签到助手。助手使用 HTTPS；仅本机访问时允许 `http://localhost` 或 `http://127.0.0.1`。弹窗会在发送前显示助手地址供用户确认；请求不携带该助手的登录 Cookie。扩展不连接扩展作者或其他服务，不包含广告、分析或遥测代码。扩展不会读取账号密码或其他标签页。用户可在 Chrome 扩展管理页面随时移除扩展。

一次性连接链接五分钟后失效，成功导入后不能重复使用。备用导出文件包含网站登录凭据；用户应只将其上传到自己信任的签到助手，并在导入后删除不再需要的副本。
