# 签到助手浏览器连接器

这是 Chrome 扩展的源码。扩展通过短时一次性链接读取当前已登录 HTTPS 网页的标题、可见签到按钮、常见状态提示和登录会话，并发送到你自己的签到助手；也提供本机 JSON 导出作为备用方式。

## 普通用户流程

### 首次安装或更新

扩展尚未上架 Chrome 网上应用店。先从部署后的助手页面展开“首次安装或更新浏览器扩展”，下载与当前服务器配套的 ZIP：

1. 解压 ZIP，在 Chrome 地址栏打开 `chrome://extensions`，开启“开发者模式”。
2. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的解压文件夹。
3. 将扩展固定到工具栏。弹窗应有链接输入框和“识别网页并连接账号”按钮，顶部显示版本。

更新时重新下载配套 ZIP，覆盖原扩展文件夹，再在扩展管理页点击刷新图标；也可移除旧扩展后加载新目录。只刷新旧文件夹不会下载更新。源码用户可使用仓库根目录的 `signin-session-exporter.zip`。

### 自动添加网站

1. 在 Chrome 中登录目标网站并打开签到页面。
2. 回到签到助手的“网站目录”，在“从当前网页自动识别并添加”点击“生成识别链接”并复制。
3. 切回目标网站标签页，点击扩展图标，粘贴链接，核对签到助手地址，点击“识别网页并连接账号”，并按 Chrome 提示授予当前网站和助手站点权限。
4. 回到签到助手，点击“打开任务并验证”。自动新增的任务保持暂停；核对识别结果，缺少规则时先返回设置补充，再开始验证。
5. 验证成功或今日已签到后，设置每天执行时间和时区，开启每日计划。

### 连接已有表单或重新登录

在具体网站配置页选择“浏览器扩展连接已登录账号”，点击“生成一次性连接链接”。回到目标网站标签页，在同一个扩展中粘贴链接并连接；结果会填回当前表单，不会另建任务。回到助手保存，再验证签到。已有任务修改账号或规则后需要重新验证。

### 备用文件导出

在扩展弹窗展开“改用本机文件导出”，下载 JSON；回到网站表单的备用会话文件入口上传并保存。无需另装 Python 或运行独立导出脚本。文件包含登录凭据，导入后删除不再需要的副本。平台接口专用表单的 Cookie、Token 和设备字段仍按页面说明提供。

扩展只在用户点击连接后读取当前 HTTPS 标签页的标题、可见按钮、匹配到的签到状态提示和资源主机名，并只向链接中显示的助手地址发送这些信息及会话；请求不携带该助手的登录 Cookie。助手地址必须使用 HTTPS；本机开发或 SSH 隧道仅允许 `http://localhost` 和 `http://127.0.0.1`。公网 HTTP 会被拒绝。连接链接五分钟过期且只能使用一次。扩展不会连接扩展作者或其他服务。新任务默认暂停，需用户手动验证后才能设置每日计划；验证时会真实执行已识别的签到操作。

## 支持范围

- 连接当前标签页 URL 对应的 Cookie，以及当前来源的 localStorage。
- 导出文件与 Playwright storage_state 兼容，大小最多 512 KiB。
- 目标网站必须使用 HTTPS；签到助手使用 HTTPS，或在本机通过 `localhost` / `127.0.0.1` 访问；每次连接前会按需申请当前网站及助手站点权限。
- 不导出密码、sessionStorage、IndexedDB、Service Worker 或其他域名的本地存储。
- 使用第三方登录、跨域授权、sessionStorage 或额外设备验证的网站，可能需要项目单独适配。

## 隐私说明

权限仅用于用户主动发起的连接或导出：activeTab 与 scripting 读取当前标签页，按需申请的 cookies 和 HTTPS / 本机回环主机权限读取当前页面 Cookie 并连接用户确认的助手站点。扩展不包含后台脚本、遥测或远程代码。详见[隐私政策](PRIVACY.md)。

## 开发与打包

在仓库根目录修改源码后，运行：

```sh
node --test browser-extension/popup.test.cjs
python tools/package_extension.py
python tools/package_extension.py --check
```

打包只包含运行文件和说明，不包含测试或个人会话。修改扩展版本时，同时更新 `manifest.json` 与弹窗顶部版本；将源码和根目录唯一的 ZIP 一起提交，CI 会检查两者一致。
