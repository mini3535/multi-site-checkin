# 签到助手浏览器连接器

这是 Chrome 扩展的源码，当前版本为 1.3.0。它可通过短时一次性链接读取当前已登录 HTTPS 网页的标题、可见签到按钮、常见状态提示和登录会话，并发送到用户指定的签到助手；也保留本机 JSON 导出作为备用方式。

## 普通用户流程

扩展尚未上架 Chrome 网上应用店。完成安装后，连接流程为：

1. 在 Chrome 中登录目标网站并打开签到页面。
2. 在签到助手生成一次性链接：在网站目录使用“从当前网页自动识别并添加”会创建一个新任务；在具体网站配置页使用会把会话和识别到的按钮填回当前表单。
3. 切回目标网站标签页，点击扩展图标，粘贴链接，核对签到助手地址，点击“识别网页并连接账号”，并按 Chrome 提示授予当前网站和助手站点权限。
4. 回到签到助手，检查识别结果并保存；自动新增的任务会保持暂停，需手动验证后才能设置每日计划。

扩展只在用户点击连接后读取当前 HTTPS 标签页的标题、可见按钮、匹配到的签到状态提示和资源主机名，并只向链接中显示的助手地址发送这些信息及会话；请求不携带该助手的登录 Cookie。助手地址必须使用 HTTPS；本机开发或 SSH 隧道仅允许 `http://localhost` 和 `http://127.0.0.1`。公网 HTTP 会被拒绝。连接链接五分钟过期且只能使用一次。扩展不会连接扩展作者或其他服务。新任务默认暂停，需用户手动验证后才能设置每日计划；验证时会真实执行已识别的签到操作。

## 商店发布状态

当前版本尚未发布到 Chrome 网上应用店，因此首次安装仍需开发者模式。已安装旧版时，请先下载新包并覆盖原扩展文件夹，再到 `chrome://extensions` 点扩展卡片上的刷新图标；也可移除旧扩展后加载新目录。仅刷新旧文件夹不会下载更新。新版弹窗显示 v1.3.0。

## 开发预览

1. 下载并解压 `signin-session-exporter.zip`。
2. 在 Chrome 打开 `chrome://extensions` 并开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择解压出的扩展文件夹。
4. 在 HTTPS 签到网站标签页中登录；在签到助手生成链接，回到扩展粘贴并连接；也可展开备用入口导出 JSON。

## 支持范围

- 连接当前标签页 URL 对应的 Cookie，以及当前来源的 localStorage。
- 导出文件与 Playwright storage_state 兼容，大小最多 512 KiB。
- 目标网站必须使用 HTTPS；签到助手使用 HTTPS，或在本机通过 `localhost` / `127.0.0.1` 访问；每次连接前会按需申请当前网站及助手站点权限。
- 不导出密码、sessionStorage、IndexedDB、Service Worker 或其他域名的本地存储。
- 使用第三方登录、跨域授权、sessionStorage 或额外设备验证的网站，可能需要项目单独适配。

## 隐私说明

权限仅用于用户主动发起的连接或导出：activeTab 与 scripting 读取当前标签页，按需申请的 cookies 和 HTTPS / 本机回环主机权限读取当前页面 Cookie 并连接用户确认的助手站点。扩展不包含后台脚本、遥测或远程代码。隐私政策源文件见 PRIVACY.md。
